# Course-Wise Subject Entry Plan (Simple)

## Your Problem (Simple)
You have one course like **10th**.
Inside that course, you have multiple classes:
- Boys Class
- Girls Class
- Mix Class

All 3 classes study the same subjects.
Right now, you must add the same subjects again and again for each class.

---

## Why This Happens in Current System
Current system saves subjects at **class level**, not direct course level.
So for each class, you need separate subject rows.

That is why repeated work is happening.

---

## Easy Solution You Need (Recommended)
Create a **Course Subject Template**.

Meaning:
1. Select Course = 10th
2. Add subjects once (Math, Science, English...)
3. Click **Apply to All Classes**
4. System automatically adds these subjects to:
   - Boys Class
   - Girls Class
   - Mix Class

---

## How It Will Work (Simple Flow)

1. Open Course Subject Template page
2. Choose course (example: 10th)
3. Enter all subjects one time
4. Click "Apply to Classes"
5. System finds all classes under that course
6. System creates missing subjects in each class
7. If subject already exists, system skips it (no duplicate)

---

## Example
Course: 10th
Subjects entered once:
- Math
- Science
- English
- Social Science

Classes under 10th:
- Boys
- Girls
- Mix

Result after one click:
- Boys gets all 4 subjects
- Girls gets all 4 subjects
- Mix gets all 4 subjects

No repeated manual typing.

---

## Safety Rules (Important)
- Do not create duplicate subjects in same class.
- If same subject already exists in target class, skip it.
- Keep current class-level subject records, so existing modules continue working.

---

## Best Implementation Option
Use this approach:
**Course Template + Apply to all classes**

Reason:
- Easy for school admin
- Low risk to existing system
- Saves major time
- Keeps current data model compatible

---

## Final Summary
Your requirement is correct and practical.
The best way is:

**Add subjects once under course, auto-copy to all classes in that course.**

This removes repeated work for Boys/Girls/Mix classes.
